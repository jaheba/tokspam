Tokspam · WebAssembly demo

Check Python source limits before parsing

Tokspam is a resource limit checker. It scans Python source for size, token count, nesting, indentation, and estimated AST depth before a parser sees it.

How to read the result

Within limits means no configured limit was exceeded. Rejected identifies a limit or screening problem. Tokspam does not validate Python syntax or decide whether code is safe to run.
